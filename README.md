# 坦克大战 · Tank Battle

经典红白机《坦克大战》(Battle City) 的网页复刻版。纯 HTML + CSS + JavaScript 单文件实现，零依赖，直接用浏览器打开即可游玩。

## 在线试玩

👉 https://gengxin936.github.io/tank-battle/

## 玩法

- 控制己方坦克，消灭每关所有敌方坦克，同时**保护基地（老鹰）**
- 共 **5 关**，难度逐关提升；敌人分 4 种：普通 / 快速 / 火力（射速快）/ 装甲（4 点血）
- 每关第 3、10、17 个敌人会掉落道具：
  - ⭐ 火力提升（第 2 级可击毁钢墙）
  - 💣 全屏爆破
  - 🛡 无敌护盾
  - ❤ 生命 +1
- 基地被摧毁或生命耗尽则游戏结束，最高分保存在本地

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| 空格 | 射击（可长按连发） |
| P / Esc | 暂停 |
| M | 静音 |
| 回车 / 点击画面 | 开始 / 重新开始 |

触屏设备会自动显示虚拟方向键与射击按钮。

## 本地运行

直接用浏览器打开 `index.html` 即可，或启动一个静态服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```

## 技术说明

- HTML5 Canvas 绘图，26×26 网格地图
- Web Audio API 合成音效（无需音频文件）
- requestAnimationFrame 游戏循环，子步进碰撞检测防穿透
- localStorage 保存最高分
